
### 1. ラテン方格法の必要性

ラテン方格法の目的は，「実験のコスト (時間、労力、参加者数) を劇的に削減しつつ，複数の要因がもたらす影響を評価すること」にある。

特に，主効果だけに関心があり，要因間の交互作用がないあるいは無視できると仮定できる場合に威力を発揮する。


例えば，ある認知課題の成績に影響を与えそうな要因として，以下の3つを考えたとする。

1. **刺激の提示時間:** 100ms, 200ms, 300ms (3水準)
2. **フォントの種類:** ゴシック, 明朝, 教科書体 (3水準)
3. **背景色:** 白, 灰, 黒 (3水準)
    

これらの効果を全て厳密に調べる要因実験を行うと，必要な条件の組み合わせは$3^3=27$通りになる。1人の参加者に27条件すべてを体験させるのは非常に負担が大きく，疲労効果なども無視できなくなる。

このような場合にラテン方格法を用いると，27通りあった条件を9通りに減らすことができる。


### 2. ラテン方格の構造

ラテン方格法では正方形のマス目を使い，3つの因子をそれぞれ「行」「列」「ラテン文字」に割り当てる。

- **行:** 因子A（例: 刺激の提示時間）
- **列:** 因子B（例: フォントの種類）
- **ラテン文字:** 因子C（例: 背景色）
    
そして，「各ラテン文字は，全ての行と全ての列に一度しか登場してはならない」というルールを満たすように，$3\times 3$の表を埋めていく。

上の例で実際にラテン方格を構成すると以下のようになる。

- 因子A（提示時間）: 100ms, 200ms, 300ms
- 因子B（フォント）: ゴシック, 明朝, 教科書体
- 因子C（背景色）: 白, 灰, 黒

|           | ゴシック | 明朝  | 教科書 |
| --------- | ---- | --- | --- |
| **100ms** | 白    | 灰   | 黒   |
| **200ms** | 灰    | 黒   | 白   |
| **300ms** | 黒    | 白   | 灰   |

この表が，実施すべき9通りの実験条件の組み合わせを示している。例えば，表の左上のマスは「提示時間100ms・ゴシック体・白」という条件を表している。

このラテン方格を用いると，各水準がバランス良く他の因子の水準と組み合わされる。例えば，背景色: 白は，提示時間100ms, 200ms, 300msのそれぞれと1回ずつ，フォント3種類とも1回ずつ組み合わさっている。これにより，他の因子の影響を均等にならしながら，各因子の主効果を推定できる。

### 3. 交互作用とのトレードオフ

ラテン方格は，以下の仮定の上に成り立っている。

> [!NOTE] 仮定
> **全ての因子間に交互作用は存在しない**


例えば，「ゴシック体は背景が白の時に最も読みやすいが、背景が黒になると極端に読みにくくなる。一方で明朝体は背景色にあまり影響されない」という交互作用が存在したとする。しかし，ラテン方格では「ゴシック体で背景が黒」という組み合わせの実験は行われない。よって，存在しない組み合わせのデータを，あたかも交互作用がないかのように補完して主効果を計算することになる。

その結果，交互作用の効果が，誤って主効果の推定値に混入してしまう可能性がある。例えば，フォントの主効果や背景色の主効果が，実際よりも過大または過小に評価されてしまう危険性がある。そのためラテン方格は，理論的に考えて，あるいは予備実験の結果から，因子間に交互作用があるとは考えにくい，と判断できる場合にのみ使うべきである。

###  4. ノイズ要因の統制

ラテン方格は，興味の対象である因子のほかに結果を乱す可能性のあるノイズ要因（変量）を2つ同時に統制したい場合に有効である。

例えば，3種類の新しいUIデザイン (A, B, C) の反応時間を比較したいとする。このとき，懸念されるノイズ要因として以下の2つが考えられる。

1. **実験の順番:** 1番目、2番目、3番目と試すうちに慣れて反応が速くなる順序効果。
2. **個人差:** 参加者ごとの能力のばらつき

このような場合，以下のようにラテン方格を組むと良い。

|         | 参加者1 | 参加者2 | 参加者3 |
| ------- | ---- | ---- | ---- |
| **試行1** | A    | B    | C    |
| **試行2** | B    | C    | A    |
| **試行3** | C    | A    | B    |

この計画により，UIデザインの効果を推定する際に，順序効果と個人差の影響を統計的に分離して取り除くことができる。これは洗練されたカウンターバランスの方法である。
